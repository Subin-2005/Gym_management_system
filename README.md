# 🏋️ Gym Management System

A full-stack **Gym Management System** developed to simplify gym operations by enabling trainers to manage members, memberships, payments, workouts, and reports through a user-friendly web application.

## 🚀 Technologies Used

### Frontend

* React.js
* HTML5
* CSS3
* JavaScript
* Axios

### Backend

* Python
* Django
* Django REST Framework (DRF)

### Database

* MySQL

### Authentication

* JWT (JSON Web Token)

### Version Control

* Git & GitHub

---

## 📌 Features

### Authentication

* Secure login using JWT Authentication
* Role-based access control

### Member Management

* Add, edit, delete, and view members
* Store member personal information
* Upload member profile photo

### Membership Management

* Create memberships
* Membership renewal
* Automatic expiry date calculation
* Membership history

### Payment Management

* Record member payments
* Track payment history
* View payment details

### Workout Management

* Assign workout plans to members
* Update workout schedules
* View workout history

### Reports & Dashboard

* Total members
* Active members
* Expired memberships
* Revenue reports
* Dashboard analytics

---

## 🗄️ Database

The application uses **MySQL** to store:

* User information
* Member details
* Membership records
* Payment records
* Workout schedules

---

## 🔐 Authentication

JWT Authentication is implemented using Django REST Framework.

Features:

* Secure Login
* Token-based Authentication
* Protected API Endpoints
* Role-based Authorization

---

## 🛠️ API

The backend exposes REST APIs for:

* Authentication
* Members
* Memberships
* Payments
* Workouts
* Reports
